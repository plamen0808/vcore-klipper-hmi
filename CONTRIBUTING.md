# Contributing

Bug reports and improvements are welcome. Before opening an issue, include:

- Printer and controller model
- RatOS, Klipper, and Moonraker versions
- Phone/tablet model, browser, and portrait or landscape orientation
- The exact steps to reproduce the issue
- Relevant browser console or Moonraker log messages, with passwords, tokens, and public IPs removed

For pull requests, keep changes focused and describe how they were checked on a Moonraker-connected printer. Do not include printer credentials, API tokens, private network dumps, or personal printer configuration files.
